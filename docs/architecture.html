3 · Signup & Profile Creation Workflow sequence

sequenceDiagram
    autonumber
    actor U as User
    participant FE as Client (React)
    participant SB as Supabase Auth
    participant PG as Postgres (trigger)
    participant PX as proxy.ts
    U->>FE: Signup (email + password)
    FE->>SB: signUp()
    SB-->>FE: user + session
    SB->>PG: INSERT auth.users
    PG->>PG: handle_new_user() — SECURITY DEFINER
    PG->>PG: INSERT public.users (id, email, anonymous_id, avatar)
    FE->>SB: verify-otp (if confirmation enabled)
    FE->>FE: onboarding
    U->>PX: GET /app
    PX->>SB: getUser() → valid → allow
    PX-->>U: Dashboard

4 · Data-Access Workflow sequence

sequenceDiagram
    autonumber
    actor U as User
    participant UI as Client Page
    participant API as Route Handler /api/*
    participant DB as Supabase PostgREST + RLS
    U->>UI: action (mood / journal / story…)
    UI->>API: fetch JSON
    API->>DB: auth.getUser()
    DB-->>API: user (or 401 stop)
    API->>DB: .from(table).select/insert/delete
    DB->>DB: RLS: auth.uid() = user_id
    DB-->>API: rows / error
    API-->>UI: {data} | {error, status}
    UI-->>U: re-render

5 · Realtime Chat Workflow sequence

sequenceDiagram
    autonumber
    actor A as User A
    participant FE as Chat Page
    participant API as /api/chat/dm · /messages
    participant DB as Supabase Postgres
    participant RT as Supabase Realtime
    actor B as User B
    A->>FE: open /app/chat/[id]
    FE->>API: GET history (+ auto-join room)
    API->>DB: select messages / direct_messages
    DB-->>FE: history
    FE->>RT: subscribe chat-{peerId} · INSERT events
    A->>API: POST send (optimistic bubble)
    API->>DB: INSERT sender = auth.uid()
    DB-->>RT: broadcast INSERT
    RT-->>A: replace temp bubble
    RT-->>B: append instantly

erDiagram
    auth_users ||--o| users : "signup trigger"
    users ||--o{ mood_logs : user_id
    users ||--o{ journal_entries : user_id
    users ||--o{ stories : user_id
    users ||--o{ story_likes : user_id
    stories ||--o{ story_likes : story_id
    users ||--o{ room_members : user_id
    chat_rooms ||--o{ room_members : room_id
    chat_rooms ||--o{ messages : room_id
    users ||--o{ messages : sender_id
    users ||--o{ direct_messages : sender_receiver
    users }o--o{ matches : user1_user2
    users {
      uuid id PK
      text email
      text anonymous_id
      text avatar_emoji
      jsonb settings
    }
    mood_logs {
      uuid id PK
      uuid user_id FK
      int mood_score
      text mood_emoji
    }
    journal_entries {
      uuid id PK
      uuid user_id FK
      text content
      bool is_private
    }
    stories {
      uuid id PK
      uuid user_id FK
      text content
      timestamptz expires_at
    }
    story_likes {
      uuid story_id FK
      uuid user_id FK
    }
    chat_rooms {
      uuid id PK
      text name
      bool is_active
    }
    room_members {
      uuid room_id FK
      uuid user_id FK
    }
    messages {
      uuid id PK
      uuid room_id FK
      uuid sender_id FK
      bool is_deleted
    }
    direct_messages {
      uuid id PK
      uuid sender_id FK
      uuid receiver_id FK
      bool is_read
    }
    matches {
      uuid id PK
      uuid user1_id FK
      uuid user2_id FK
      float similarity_score
    }
